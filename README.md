# Stream Elements custom chat

Based on [https://github.com/StreamElements/widgets/tree/master/CustomChat](https://github.com/StreamElements/widgets/tree/master/CustomChat)

## My modifications
**Important**\
Obviously this modifications works only in the overlay. When you put [wave], for example, it will still show up in twitch's native chat

### Added chat modifiers:
  To apply a modifier, put [`mod`] at the beginning of your message

  - [wave] Makes the text move like a wave
  - [rainbow] Makes the text change color
  
  You can mix multiple modifiers: [rainbow, wave]
